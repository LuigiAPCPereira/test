# Produto — Controle de Notas Fiscais

- Propósito: reduzir digitação manual no controle de NFs de serviço recebidas em PDF.
- Usuário principal: colaborador que recebe/processa NFs e posteriormente informa OS, validade e observações.
- Fonte operacional: biblioteca de documentos + lista SharePoint corporativas.
- Modos: automático em nuvem; imediato a partir de arquivo selecionado; desktop planejado para leitura local rápida.
- Fora do escopo atual: alterar PDFs originais, preencher automaticamente OS/validade, usar credenciais fora do ambiente corporativo.
